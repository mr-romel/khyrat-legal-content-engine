Privacy Policy

Effective date: October 13, 2026

This Privacy Policy describes how Khyrat Legal Content Engine (“the application”) handles information when its operator connects a Google account to use Blogger publishing features.

Information accessed

With the account holder’s authorization, the application uses Google OAuth credentials and the Blogger API to perform requested publishing operations. Depending on the operation, this can include identifying the authorized Blogger account or blog and creating or managing posts.

How information is used

Information and permissions are used only to operate the application’s requested content workflow, including preparing and publishing content to Blogger. The application does not sell personal information or use Google user data for advertising.

Storage and security

OAuth credentials are intended to be stored as restricted GitHub Actions secrets for automated operation, not committed to the source-code repository. The operator should keep credential files private, restrict repository access, and revoke the application’s access from their Google Account security settings when access is no longer needed. No internet service can guarantee absolute security.

Sharing and retention

The application does not intentionally sell or share Google user data with data brokers. Data may be processed by Google, GitHub, and the connected publishing services as needed to provide the workflow. Credentials and workflow records should be retained only as long as operationally necessary; the operator can revoke Google access and remove stored secrets to stop future authorized access.

Your choices

You can stop using the integration, revoke its access in your Google Account, or remove the OAuth secret from the project’s GitHub settings. Revoking access may stop automated publishing.

Contact

For privacy questions or requests, contact the project operator through the project issue tracker. Do not post passwords, OAuth tokens, or other secrets in public issues.
